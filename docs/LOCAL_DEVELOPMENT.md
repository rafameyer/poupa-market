# Local Development

## Prerequisites

- Node.js 20 LTS or newer
- npm 10 or newer

Check your environment:

```bash
node -v
npm -v
```

## Install dependencies

```bash
npm install
```

## Run the development server

```bash
npm run dev
```

Open `http://localhost:3000`.

## Lint

```bash
npm run lint
```

## Build locally

```bash
npm run build
```

## Run the production build

```bash
npm start
```

## Open in VS Code

```bash
code .
```

If `code` is not available, install it from the VS Code Command Palette using `Shell Command: Install 'code' command in PATH`.
